
# 🏏 ODI Cricket Analytics Dashboard

An interactive ODI Cricket Analytics Dashboard built using Python, Flask, Pandas, HTML, CSS and JavaScript.

## 📊 Project Features

- Total Players, Runs, Centuries and Matches
- ODI Record Holders
- Player Profile Cards with Images
- Search Players
- Filter Players by Country
- Country-wise Performance Analysis
- ODI World Cup Winners Timeline (1975–2023)
- World Cup Titles by Team

## 🛠️ Technologies Used

- Python
- Pandas
- Flask
- HTML
- CSS
- JavaScript

## 📁 Project Structure

- app.py – Flask application
- templates/index.html – Dashboard interface
- static/style.css – Dashboard styling
- static/images/players – Player images
- CSV – ODI batting dataset

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the application

```bash
python app.py
```

### 4. Open in browser

http://127.0.0.1:5000/
